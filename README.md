# Каталог сборок Teyes – Teyes Sibir

Таблица подбора мультимедиа Teyes: марка → модель → поколение → штатная сборка (рамка, проводка, цены, товары, фото торпеды).

Страница: https://tema-mail.github.io/teyes-podbor/

## Как обновить
Данные живут в `~/Documents/Teyes-контент/материалы/подбор-мультимедиа/` (карточки моделей).
1. Собрать `последний.html` обычным конвейером (`_визуал-сайт/`, см. СОСТОЯНИЕ_ПРОЕКТА.md).
2. `python3 ~/Documents/Teyes-контент/материалы/подбор-мультимедиа/_визуал-сайт/build_pages.py ~/Documents/teyes-podbor`
3. Коммит и push – GitHub Actions выкладывает на Pages.

Фото ужаты в WebP (до 1600 px) и лежат в `photos/`. Страница закрыта от поиска (noindex).
